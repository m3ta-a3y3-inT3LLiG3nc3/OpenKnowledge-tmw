# OpenNotebook Integration

This skill equips agents to interact with an **OpenNotebook** instance (the open-source NotebookLM alternative) running locally or remotely.

## Key Capabilities

1. **Grounded Source Ingestion**: Push any OpenKnowledge markdown file or directory into OpenNotebook as a source for multi-source synthesis and podcast generation.
2. **Note Synchronization**: Pull synthesized notes, insights, and summaries from OpenNotebook into OpenKnowledge markdown documents.
3. **Notebook Search & Chat**: Execute full-text and vector search over ingested notebook sources or chat with sources directly.

## Using the Bridge CLI

From the OpenKnowledge project root, execute:

```bash
# Verify connectivity
node scripts/opennotebook-bridge.mjs status

# List available notebooks
node scripts/opennotebook-bridge.mjs list-notebooks

# Create a new notebook
node scripts/opennotebook-bridge.mjs create-notebook "Project Architecture" "Deep dive research"

# Ingest a single OpenKnowledge document as a source
node scripts/opennotebook-bridge.mjs push-doc ./specs/architecture.md <notebook-id>

# Ingest an entire folder of notes/specs
node scripts/opennotebook-bridge.mjs push-dir ./docs <notebook-id>

# Pull notes generated by OpenNotebook into local markdown files
node scripts/opennotebook-bridge.mjs pull-notes <notebook-id> ./opennotebook-notes

# Search notebook sources and notes
node scripts/opennotebook-bridge.mjs search "authentication flow"

# Ask questions grounded in notebook sources
node scripts/opennotebook-bridge.mjs chat <notebook-id> "What are the key trade-offs discussed in the architecture doc?"
```

## Configuration

Set the environment variables if OpenNotebook runs on a custom port or with authentication enabled:

- `OPENNOTEBOOK_API_URL`: Base URL of OpenNotebook REST API (default: `http://localhost:5055`)
- `OPENNOTEBOOK_PASSWORD`: Bearer authentication token if password protection is configured in OpenNotebook.
